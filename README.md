# Netflix Landing Page Clone

A responsive front-end clone of the Netflix landing page built with **HTML5** and **CSS3**. The project recreates the visual design of Netflix's homepage, featuring a modern hero section, feature highlights, embedded promotional videos, and a responsive layout across desktop and mobile devices.

---

## Overview

This project replicates the look and feel of Netflix's official landing page using only HTML and CSS. It focuses on responsive web design, layout composition, and UI implementation without relying on JavaScript frameworks or external libraries.

The application demonstrates the ability to build pixel-inspired interfaces while following modern frontend development practices.

---

## Features

* Responsive Netflix-inspired landing page
* Hero section with background image
* Navigation bar with Netflix branding
* Feature sections with images and videos
* Embedded promotional media
* Clean and structured page layout
* Mobile-friendly responsive design
* Pure HTML and CSS implementation

## Getting Started

### Clone the repository

```bash
git clone https://github.com/arham-1122/Netflix-Clone.git
```

### Navigate to the project

```bash
cd Netflix-Clone
```

### Run the project

Open the `index.html` file in your browser or launch it using **Live Server** in Visual Studio Code.
